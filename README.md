# Kripa Portfolio

My personal portfolio website — showcasing UI/UX design and software development projects.

## Live site
https://kripa19-08.github.io/kripa-portfolio

## Built with
- HTML5
- CSS3 (custom animations, responsive design)
- JavaScript (image carousels, mobile navigation, interactive project folders)

## Features
- Responsive layout for desktop, tablet, and phone
- Two interactive project folders — UI/UX Design and IoT
- Sliding image carousels for each project
- Contact form and downloadable resume

## Projects featured
- **SpeedToll** — UI/UX mobile app design (Figma prototype)
- **MindUnwind** — Mental wellness app, hackathon project (Figma prototype)
- **Smart Accident & Disaster Alert System** — Arduino-based IoT safety system ([GitHub repo](https://github.com/Kripa19-08/smart-accident-disaster-alert-system))
